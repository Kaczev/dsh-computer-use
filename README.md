# dsh-computer-use · 0.5.2-k2-1

原插件由 **Yu-tao-Li** 开发：[Yu-tao-Li/dsh-computer-use-win](https://github.com/Yu-tao-Li/dsh-computer-use-win)。本版基于上游 0.5.2；插件的主要功能、架构和界面都来自原作者及贡献者。我们只为实际使用中遇到的问题做了少量补丁。

本版包名：`@kaczev/dsh-computer-use`。

## 我们的补丁

### 0.5.2-k2-1

本次只修测试环境并加固焦点回归：Electron GUI 测试使用临时运行时副本，保持默认沙箱；焦点检查监听接管助手的实际前台归属。不新增产品功能补丁，运行逻辑与 0.5.2-k2 相同。

### 0.5.2-k2

- **修复空定位字段引起的通道冲突。** `browserTab: ""` 或纯空白不再被识别为浏览器目标；空的 `windowTitle` 也会清理。桌面调用可以保留这些占位字段，同时使用 HWND 或 PID，且不需要浏览器连接。
- **保留真实目标冲突检查。** 非空 `browserTab` 或页面元素 ID 与桌面定位字段、屏幕坐标混用时仍然拒绝；错误会列出被识别为冲突目标的字段和值。浏览器目标与非空 UIA 元素 ID 混用也会拒绝。
- **补充参数说明与回归测试。** 工具导出的 MCP schema 原本就将定位字段设为可选；本版明确说明桌面调用应省略 `browserTab`，并兼容空占位。测试覆盖空白字段、HWND/PID、仅 HWND、浏览器关闭时的桌面读取、页面 ID 冲突和真实 WinForms 的截图、UIA 读取。

本版没有修改 DSH 或模型供应商把可选字段转换为必填字段的适配逻辑。为兼容现有 MCP 客户端，保留扁平参数 schema，在运行时检查目标互斥，不新增 `oneOf` 分支。

### 沿用的 k1 补丁

- 空的 `elementId` 使用同时提供的坐标；非空 ID 仍优先，无效或过期 ID 不会静默退回坐标。
- 使用独立的分叉包名，并修正客户端注册 ID；MCP 服务名仍为 `wincu`。
